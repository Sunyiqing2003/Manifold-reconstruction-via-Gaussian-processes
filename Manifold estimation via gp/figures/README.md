## Unified benchmark figures

Generated by `../benchmark/manifold_benchmark.py` from the pilot results in
`../results/benchmark/`. These are computational results from the local
reproduction framework, not figures extracted from Dunson and Wu (2026).

| File | Diagnostic |

| `fig-benchmark-noise.png` | Reconstruction error versus ambient noise |
| `fig-benchmark-sample-size.png` | Reconstruction error versus independently generated sample size |
